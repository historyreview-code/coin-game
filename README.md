# 🪙 猜金币 · 经典两箱问题

> 一个箱子装着两枚金币，另一个装一金一银。翻出一枚金色——坚持还是换箱？

![猜金币](/outputs/screenshot.png)

一款基于网页的交互式概率悖论游戏，源自 **Bertrand's Box Paradox**（贝特朗箱悖论）。玩家通过动手翻硬币来直观感受条件概率的奇妙之处。

## 🎮 游戏规则

1. **随机分配** — 每局系统随机分配两个宝箱：一个装两枚金币（GG），另一个装一枚金币和一枚银币（GS）
2. **翻硬币** — 点击任意一枚硬币翻转查看
3. **翻到金色** 🟡 — 选择「坚持此箱」或「换另一箱」
4. **翻到银色** ⚪ — 此局作废，自动重开

> 🤯 翻出金色后，当前箱子是双金箱的概率不是 50%，而是 **2/3（≈66.7%）**。坚持比换箱更优！

## ✨ 功能特性

| 按钮 | 功能 |
|------|------|
| 🔀 随机换位 | 交换左右箱子的位置，排除位置干扰 |
| 🔄 重开新局 | 重置统计数据并开始新一局 |
| 🔳 暗箱/明牌 | 切换是否显示箱内金币/银币分布 |
| 📊 模拟统计 | 蒙特卡洛模拟，快速验证概率 |
| ❓ 帮助 | 游戏规则与概率说明 |

- **语音导览**：全程中文语音播报（系统 TTS），无需手动操作
- **实时统计**：坚持/换箱的胜率实时更新
- **手机适配**：完全适配手机屏幕，两箱并列展示，一屏即可完成所有操作
- **宝箱特效**：渐变边框、发光动画、金币翻转动效

## 📊 概率理论

| 决策 | 获胜概率 |
|------|----------|
| 🏠 **坚持此箱** | **66.7%** |
| 🔄 换另一箱 | 33.3% |
| ⚪ 翻出银面（无效局） | 占总局数 25% |

> 翻出金色后，当前箱子有 2/3 概率是双金箱（因为双金箱有 2 个金币正面，一金一银箱只有 1 个）。

## 🛠 技术栈

- 纯 HTML + CSS + JavaScript，零依赖
- CSS 动画与渐变
- Web Speech API（语音播报）
- Web Audio API（翻转音效）
- 完全响应式设计

## 🚀 运行

直接用浏览器打开 `index.html` 即可游玩。可部署到任何静态托管服务（GitHub Pages、Vercel、Netlify 等）。
